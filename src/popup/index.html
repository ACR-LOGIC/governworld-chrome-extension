          Instructions & User Guidance

          Local-First

          1. Overview & Architecture

          Zero Egress

          GovernWorld brings enterprise-grade detection and redaction directly into your browser. All pattern matching, OCR text recognition, visual overlay masking, and document flattening execute entirely on this device. No document bytes, form values, or page text leave your browser.

          2. Local-Only Processing

          Device Sandbox

          By default, GovernWorld operates in Local Only mode. Detection runs in isolated Web Workers and browser sandboxes without network requests. Temporary in-memory session data is discarded automatically upon session clear or tab closure.

          3. Scanning Web Pages

          Alt+Shift+S
          1. Navigate to any webpage containing sensitive information.
          2. Click Scan Page in the extension popup or press Alt+Shift+S.
          3. Review the categorized findings in the results list.
          4. Check the findings you wish to protect and click Apply selected masks.

          4. Visual Masking & Clipboard Safety

          DOM Overlays

          Page masks are non-destructive visual overlays rendered in a protected Shadow DOM. The original website HTML and underlying server data are never mutated. While masks are active, using Copy redacted text copies the sanitized text with solid redaction blocks.

          5. Document Scanning & Redaction

          PDF / DOCX / Image
          1. Switch to the Documents tab.
          2. Drag and drop a PDF, Word document (.docx), or image (.png, .jpg, .webp).
          3. Watch the live on-device processing status as optical recognition and detection run.
          4. Inspect the page thumbnails and detected sensitive fields.
          5. Click Redact selected & download to receive a permanently flattened, redacted copy.

          6. Verification Lifecycle

          3-Stage Proof

          GovernWorld implements a rigorous 3-stage lifecycle for document security:

          • Detected: Potential PII/PHI entities identified via deterministic rules.
          • Redacted: Opaque blackout boxes rendered across target coordinates.
          • Verified: Output bitmap re-evaluated on-device to prove zero readable pixel bleed before download.

          7. Redaction Wizard (Custom Rules)

          Custom Logic
          1. Switch to the Wizard tab and click Create Custom Rule.
          2. Enter positive examples (strings that should match) and negative examples (strings to ignore).
          3. Click Analyze Examples to generate candidate regular expressions locally.
          4. Select a proposed pattern, refine the regex, and test it against interactive sample text.
          5. Assign a category lane, confidence rating, and label, then click Save Rule Locally.

          Saved rules immediately integrate into all subsequent page and document scans.

          8. Detection Categories & Presets

          Compliance

          GovernWorld includes built-in detectors for: SSN, Medical Record Number (MRN), Member ID, DOB, Provider NPI, DEA Number, Medicare Beneficiary ID (MBI), Payment Cards (Luhn validated), API Keys & Secrets, Email, US Phone, US Address, Canadian SIN, UK NHS, Indian Aadhaar, Indian PAN, Australian TFN, Brazilian CPF, and Possible Names.

          Pre-configured compliance presets include HIPAA (Healthcare), PCI DSS (Payments), GDPR (EU Personal Data), PIPEDA (Canada), UK GDPR / NHS (UK), DPDP Act (India), Privacy Act (Australia), LGPD (Brazil), and Developer (API secrets).

          9. Cloud Features & API Connectivity

          API Ready

          Cloud features are intentionally locked and disabled in this standalone release. All processing remains strictly local. The extension architecture retains standardized API hooks and gateway connectors so organizations can link enterprise workspace gateways in future deployments without architectural changes.

          10. Audit Log & Cryptographic Proof

          Ed25519 Signed

          All protection actions generate an immutable, cryptographically signed audit log stored locally. Click Export audit log in Settings to download the JSONL audit ledger and its corresponding cryptographic signature for compliance verification.

          11. Free, Privacy-Respecting & Community Supported

          Community Powered

          GovernWorld is designed to protect user privacy without compromise. Unlike traditional browser extensions:

          • 100% Local-First: All regex matching, OCR text recognition, DOM overlays, and document flattening happen entirely on your computer.
          • Zero Data Monetization: We never log, sell, transmit, or inspect your documents, scanned text, or browsing history.
          • Zero Paywalls for Local Security: Every core local detection and redaction capability is completely free.

          If GovernWorld helps protect your workflow, consider supporting development, offline models, and validator maintenance via Buy Me a Coffee ☕.
