          Instructions & User Guidance

          Local-First

          1. Overview & Architecture

          Zero Egress

          GovernWorld brings enterprise-grade detection and redaction directly into your browser. All pattern matching, OCR text recognition, visual overlay masking, and document flattening execute entirely on this device. No document bytes, form values, or page text leave your browser.

          2. Local-Only Processing

          Device Sandbox

          By default, GovernWorld operates in Local Only mode. Detection runs in isolated Web Workers and browser sandboxes without network requests. Temporary in-memory session data is discarded automatically upon session clear or tab closure.

          3. Scanning Web Pages

          Alt+Shift+S
          1. Navigate to any webpage containing sensitive information.
          2. Click Scan Page in the extension sidepanel or press Alt+Shift+S.
          3. Review the categorized findings in the results list.
          4. Check the findings you wish to protect and click Apply selected masks.

          4. Visual Masking & Clipboard Safety

          DOM Overlays

          Page masks are non-destructive visual overlays rendered in a protected Shadow DOM. The original website HTML and underlying server data are never mutated. While masks are active, using Copy redacted text copies the sanitized text with solid redaction blocks.

          5. Document Scanning & Redaction

          PDF / DOCX / Image
          1. Switch to the Documents tab.
          2. Select your target OCR language (English, Spanish, French, German, Japanese, Portuguese).
          3. Drag and drop a PDF, Word document (.docx), or image (.png, .jpg, .webp).
          4. Use the Studio Canvas Tools to draw custom redaction boxes or toggle detected items.
          5. Select your desired Redaction Style (Blackout, Whiteout, or Custom Text Stamp).
          6. Click Redact selected & download to receive a permanently flattened copy.

          6. Verification Lifecycle

          3-Stage Proof

          GovernWorld implements a rigorous 3-stage lifecycle for document security:

          • Detected: Potential PII/PHI entities identified via deterministic rules.
          • Redacted: Opaque boxes painted across target coordinates.
          • Verified: Output bitmap re-evaluated on-device to prove zero readable pixel bleed before download.

          7. Redaction Wizard (Custom Rules)

          Custom Logic
          1. Switch to the Wizard tab and click Create Custom Rule.
          2. Enter positive examples (strings that should match) and negative examples (strings to ignore).
          3. Click Analyze Examples to generate candidate regular expressions locally.
          4. Select a proposed pattern, refine the regex, and test it against interactive sample text.
          5. Assign a category lane, confidence rating, and label, then click Save Rule Locally.

          Saved rules immediately integrate into all subsequent page and document scans.

          8. Detection Categories & Global Presets

          Global Compliance

          GovernWorld includes built-in validators for: SSN, ITIN, Medical Record Number (MRN), Member ID, DOB, Provider NPI (checksum), DEA Number, Medicare ID (MBI), Payment Cards (Luhn validated), API Keys & Secrets, Email, US Phone, US Address, Canadian SIN, UK NHS Number, Indian Aadhaar (Verhoeff), Indian PAN, Australian TFN, Brazilian CPF, and Possible Names.

          Pre-configured global presets: HIPAA (Healthcare), PCI DSS (Payments), GDPR (EU), PIPEDA (Canada), UK GDPR / NHS (UK), DPDP Act (India), Privacy Act (Australia), LGPD (Brazil), and Developer (API secrets).

          9. Proactive Paste & Prompt Shield

          Chat & LLM Guard

          The Proactive Paste Shield intercepts clipboard paste events on input fields, textareas, and chat interfaces (optimized for ChatGPT, Claude, Gemini, Slack, and web forms). When sensitive data is detected:

          • A floating Shadow DOM review modal displays masked previews of the detected items.
          • Sanitize & Paste: Replaces detected secrets/PII with solid [REDACTED] blocks before pasting.
          • Paste Unchanged: Pastes raw content if deliberately intended.
          • Cancel: Aborts paste completely (Esc).

          10. Right-Click Context Menus & Shortcuts

          Direct Access

          Perform privacy actions on any web page without needing to open the sidepanel:

          • Redact selection to clipboard: Highlight text and right-click to copy sanitized text with sensitive fields redacted.
          • Mask selected text / element: Highlight an element and right-click to instantly overlay an in-browser privacy mask.
          • Scan whole page: Right-click anywhere or press Alt+Shift+S.
          • Toggle masks: Press Alt+Shift+M.
          • Open Side Panel: Press Alt+Shift+P.

          11. Multi-Language OCR Architecture

          6 Languages

          GovernWorld's offline OCR engine processes document images and PDFs in 6 languages: English (eng), Spanish (spa), French (fra), German (deu), Japanese (jpn), and Portuguese (por). Select your target language in Document Studio or Settings.

          12. Document Redaction Styles

          Styles & Stamps

          Choose how redacted areas are rendered on exported PDF, Word, and Image files:

          • Blackout: Solid opaque black rectangles (standard for legal & forensic security).
          • Whiteout: Clean white fill (ideal for printed forms and letterheads).
          • Text Stamp: Opaque fill with centered labels such as [REDACTED], [CONFIDENTIAL], or [PHI REMOVED].

          13. Cloud Features & API Connectivity

          API Ready

          Cloud features are intentionally locked and disabled in this standalone release. All processing remains strictly local. The extension architecture retains standardized API hooks and gateway connectors so organizations can link enterprise workspace gateways in future deployments.

          14. Audit Log & Cryptographic Proof

          Ed25519 Signed

          All protection actions generate an immutable, cryptographically signed audit log stored locally. Click Export audit log in Settings to download the JSONL audit ledger and its corresponding cryptographic signature for compliance verification.

          15. Free, Privacy-Respecting & Community Supported
